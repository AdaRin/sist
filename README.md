# SGPI de CodeNova Solutions S.R.L.

Trabajo Práctico Integrador 4 de Organización Empresarial, UTN TUP a Distancia. Caso académico ficticio preparado por Adriana Edith Rincón.

## Alcance

Documentación del Sistema de Gestión de Proyectos e Inventario de Recursos Técnicos (SGPI). El proceso modelado es la solicitud y asignación de equipos o licencias a proyectos. No se afirma que el software esté implementado ni que los indicadores se hayan medido.

## Archivos

- `docs/proceso-bpmn.md`: participantes, pasos, decisiones y diagrama del proceso.
- `backlog.csv`: historias de usuario y criterios de aceptación iniciales.
- `TP4_Adriana_Rincon.docx`: informe editable del TP4.

## Flujo colaborativo

La rama `main` conserva la versión integrada. Los cambios se preparan en ramas `docs/*` o `feat/*`, se registran con commits descriptivos y se proponen mediante Pull Request. La revisión por pares y la aprobación humana deben realizarse antes de integrar los cambios.
